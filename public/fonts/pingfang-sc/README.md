# PingFang SC web subsets

Source archive:

`E:\OneDrive\Design files sync\AI\Proj. design atlas\Materials\font\PingFang-main\PingFangSC-Regular.otf`

The web assets retain the three weights used by the site and are split by script so English-only pages do not download the CJK subsets.

- `Regular`: body and ordinary interface copy.
- `Medium`: navigation, titles and emphasized interface copy.
- `Semibold`: bold rich text and strong emphasis.

Each weight has a small Latin subset and a separately loaded CJK subset. The CJK subsets include the current published content, GB2312 level-one common Simplified Chinese characters, CJK punctuation and full-width forms. Generated with fontTools 4.63.0 and WOFF2 compression. Characters outside the subset fall back to the system Chinese font.
